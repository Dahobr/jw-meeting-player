# UI/UX改善 第2段階 設計書

**目標:** プレイリスト操作の高度化（並び替え、物理削除、重複回避）。

## 変更内容

### 1. ドラッグ＆ドロップによるアイテム並び替え
- **目的**: ユーザーが自由に再生順序を変更できるようにする。
- **実装**: レンダラープロセス (`src/renderer/main.js`)
- **詳細**: HTML5 Drag and Drop API を使用。並び替え完了後、`saveAppData()` で `playlist.json` を更新。

### 2. ファイルの物理削除と排他制御
- **目的**: 不要なメディアファイルを自動で削除し、ディスク容量を節約する。
- **実装**: 
  - メインプロセス: `fs.unlink` を実行する IPC ハンドラを追加。
  - レンダラープロセス: アイテム削除時およびプレイリスト削除時に、対象ファイルのパスをメインプロセスへ送信。
- **エラーハンドリング**: 
  - ファイルが再生中などで削除できない場合、メインプロセスからエラーを返し、レンダラーで「再生中はその操作を行えません」というダイアログを表示する。
  - 削除成功後、`saveAppData()` を実行して `playlist.json` からもデータを完全に消去する。

### 3. ダウンロード時のファイル名重複回避
- **目的**: プレイリスト間でファイルを共有せず、個別に削除できるようにする。
- **実装**: メインプロセス (`main.js`)
- **詳細**: ダウンロード保存先パスを決定する際、同名ファイルがあれば `(1)`, `(2)` ... と未使用の番号が見つかるまで付与する。

## 成功基準
1. アイテムをドラッグして移動させると、その順序でプレイリストが更新・保存される。
2. アイテムやプレイリストを削除した際、ダウンロードフォルダから該当ファイルが物理的に削除される。
3. 再生中のアイテムを削除しようとすると、警告ダイアログが表示され削除が中断される。
4. 同じファイルを複数回ダウンロードしても、別々のファイル名で保存され、既存ファイルを上書きしない。
