# Zoom設定チュートリアル刷新設計書 (2026-05-25)

## 概要
現在の「Guia de Operação」を、ユーザー主体で進められるインタラクティブなオーバーレイ形式のチュートリアルへ刷新する。Zoomの複雑な初期設定（特にConfiguraçõesとAlt+S設定）を自動化・ガイドし、継続してアプリケーションの操作説明へシームレスに接続する。

## チュートリアル構成
### 1. UI/UX
- **形式:** アプリ画面へのオーバーレイ（モーダル形式）。
- **進捗:** ステップ形式。ユーザーが主体的に「次へ」「スキップ」を選択可能。
- **初回起動:** 自動表示。
- **再表示:** メニューから手動起動可能。
- **スキップ:** 途中で閉じた場合、次回は最初から開始する。

### 2. ステップフロー
1. **モード紹介:** Zoomの3つのモードに関する説明。
2. **Zoom設定ガイド:** 
   - 「設定画面を開く」ボタンを配置。
   - 押下時にネイティブ実行ファイル（`.exe`）を実行し、Zoomの設定画面を自動表示。
3. **Alt+S設定ガイド:** グローバルショートカット設定の解説。
4. **操作ガイド:** 以下の詳細ステップで操作を習得。
   - **Step 4.1: プレイリストの作成:** リスト追加、ドラッグ＆ドロップの操作。
   - **Step 4.2: 再生・停止コントロール:** 基本再生ボタンと状態フィードバックの解説。
   - **Step 4.3: Zoom共有連携:** 再生と共有の同期フロー。
   - **Step 4.4: ショートカット活用:** Alt+Sによるクイック操作の実践。
   - 最後まで表示完了、またはスキップされた時点で設定を永続化。

### 3. データ管理
- **設定保存:** `storageManager.js` を使用し、チュートリアル非表示フラグを永続化。

## 実装仕様
- **UI:** CSSでのオーバーレイ表示実装。
- **Zoom連携:** ネイティブの `ZoomKeySender.exe` または `ZoomControlManager.exe` を利用（Python依存の排除）。
- **フロー制御:** `renderer/js/uiManager.js` におけるチュートリアル進行状態の管理。
