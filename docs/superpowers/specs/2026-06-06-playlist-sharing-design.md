# プレイリスト共有システム 設計仕様書 (Design Spec)

## 1. 概要
ユーザーが作成したプレイリストを他のユーザーと簡単に共有するためのシステム。WhatsApp Webとの統合、スマートなエクスポート（ハイブリッド方式）、およびダウンロード監視による自動インポートを実現する。

## 2. 目標
- **利便性:** ユーザーがファイルを探す手間を省き、コピー＆ペーストで共有できること。
- **効率性:** 動画実体を極力含まず、URLを活用してZIPサイズを軽量化（WhatsApp最適化）すること。
- **整合性:** プレイリストごとにサブフォルダを作成し、ファイル名の重複や管理の混乱を防ぐこと。
- **自動化:** 受信側がファイルをダウンロードした瞬間にアプリが検知し、ワンクリックで取り込めること。

## 3. 主要機能

### 3.1 フォルダ構造の変更
メディアファイルの保存場所をプレイリスト単位で分離する。
- **ベースパス:** `downloads/[Playlist_Name_or_ID]/`
- プレイリスト削除時にフォルダごと削除することで、不要なファイルをクリーンアップ可能にする。

### 3.2 スマート・エクスポート (共有)
プレイリストを専用拡張子 `.jwmp` (中身はZIP) としてパッケージ化する。
- **画像:** 常に実体を同梱。
- **オンライン動画:** ソースURLを記録し、実体は含めない（リンク方式）。
- **オフライン動画:** 自動的に実体を同梱（ユーザーへの確認は不要）。
- **共有アクション:** 
  1. `.jwmp` ファイル生成後、自動的にクリップボードにファイルをコピー。
  2. ユーザーに「クリップボードにコピーしました。WhatsAppのチャット画面で Ctrl+V で貼り付けてください」というガイドを表示。
  3. ガイドの確認後、自動的に WhatsApp Web を表示。

### 3.3 自動インポート (受信・ダウンロード監視)
アプリ内ブラウザでのダウンロードを監視し、拡張子に応じて自動的に振り分けを行う。
- **.jwmp ファイル検知:**
    - アプリ専用のプレイリストファイルとして認識。
    - ダウンロードをインターセプトし、新しいプレイリストとして追加するダイアログを表示。
- **サポートされているメディアファイル (.mp4, .jpg, .png 等) 検知:**
    - プレイリストのアイテムとして認識。
    - ダウンロード完了後、**現在選択されているプレイリスト**に自動的にアイテムとして追加する。
- **ID衝突回避:** プレイリストのインポート時に既存のIDと重複した場合は、新しいIDを再割り当てする。
- **自動ダウンロード:** プレイリストインポート時、実体がない動画アイテムは裏で自動的に再ダウンロードを開始。

## 4. 技術的な変更点

### 4.1 データモデルの拡張
`playlists.json` のアイテムに以下のフィールドを追加。
- `sourceUrl`: オリジナルのURL（動画・画像追加時に裏側で自動取得し、コンテキストメニューは変更しない）。
- `playlistId`: 紐付け先のプレイリストID。

### 4.2 SiteViewManager の強化
- **WhatsAppボタン:** ナビゲーションヘッダーの右側に WhatsApp ロゴの**アイコンボタン**を追加。他のナビゲーションボタンと区別し、一目でチャットツールと分かるようにする。


### 4.3 DownloadManager の強化
- `.jwmp` ファイルのハンドリングロジックの追加。
- クリップボードへのファイルコピー機能の実装。

## 5. ユーザーフロー

### 送信側
1. プレイリストの「⋮」メニューから「共有」を選択。
2. アプリが背景で `.jwmp` を作成し、クリップボードにコピー。
3. アプリ内のWhatsApp画面が開く。
4. 相手を選んで `Ctrl+V` で送信。

### 受信側
1. アプリ内のWhatsAppで届いた `.jwmp` をクリック。
2. アプリが検知し「インポートしますか？」と通知。
3. 「はい」で完了。必要に応じて動画が自動ダウンロードされる。

## 6. 成功基準
- WhatsAppで200MB以下のサイズで安定して共有できること。
- インポート時に既存のファイルと衝突せず、正しくメディアが紐付くこと。
- ユーザーが手動でファイルエクスプローラーを操作する必要がなくなること。
