# JW Meeting Player

[English](#jw-meeting-player) | [Português](#jw-meeting-player-português---brasil)

JW Meeting Player is a desktop application designed to streamline media playback and Zoom screen sharing for meetings.

## Motivation

This application was created to solve several common pain points during meeting operations:

* **Zoom Focus Stealing:** When using a second screen for media playback, Zoom often steals focus, forcing the operator to constantly reopen or refocus the media player. This app ensures seamless playback control.
* **Fragmented Media Sources:** Media files are often scattered across different locations. This app centralizes them into a single playlist, significantly simplifying meeting operations.

## Key Features

* **Zoom Sharing Automation:** Automatically triggers Zoom screen sharing when media playback begins and stops when it ends.
* **Standby Mode:** Provides a standby state before media playback, ensuring smooth transitions.
* **Streamlined Workflow:** While media files from [jw.org](https://www.jw.org) must be downloaded manually to comply with their Terms of Use, this app embeds a browser to facilitate this process. Once downloaded, files are automatically imported into the application, minimizing manual effort.

## Compliance Note

To adhere to the terms of use for jw.org, the application requires users to manually download media files. The app is designed to make this manual process as efficient as possible by integrating a browser directly into the interface.

# JW Meeting Player (Português - Brasil)

[English](#jw-meeting-player) | [Português](#jw-meeting-player-português---brasil)

O JW Meeting Player é um aplicativo de desktop projetado para otimizar a reprodução de mídia e o compartilhamento de tela via Zoom para reuniões.

## Motivação

Este aplicativo foi criado para resolver problemas comuns durante a operação de reuniões:

* **Zoom roubando o foco:** Ao usar uma segunda tela para reprodução de mídia, o Zoom frequentemente assume o foco, forçando o operador a reabrir ou reativar constantemente o player de mídia. Este aplicativo garante um controle de reprodução ininterrupto.
* **Fontes de mídia fragmentadas:** Arquivos de mídia muitas vezes ficam espalhados em diferentes locais. Este aplicativo os centraliza em uma única lista de reprodução, simplificando significativamente as operações de reunião.

## Principais Funcionalidades

* **Automação de Compartilhamento no Zoom:** Aciona automaticamente o compartilhamento de tela do Zoom quando a reprodução da mídia começa e para quando ela termina.
* **Modo de Espera (Standby):** Oferece um estado de espera antes da reprodução da mídia, garantindo transições suaves.
* **Fluxo de Trabalho Otimizado:** Embora os arquivos de mídia do [jw.org](https://www.jw.org) devam ser baixados manualmente para cumprir seus Termos de Uso, este aplicativo incorpora um navegador para facilitar esse processo. Uma vez baixados, os arquivos são importados automaticamente para o aplicativo, minimizando o esforço manual.

## Nota de Conformidade

Para aderir aos termos de uso do jw.org, o aplicativo exige que os usuários baixem manualmente os arquivos de mídia. O aplicativo foi projetado para tornar esse processo manual o mais eficiente possível, integrando um navegador diretamente na interface.
