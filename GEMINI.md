# Project Instructions

## Language Preferences

- **Communication:** Always use Japanese for interaction with the user.
- **Commit Messages and Code Comments:** Always use English for Git commit messages and comments within the source code.

## Workflows

- **Bug Fixes and Implementation:** Before starting any fix or implementation, always explain the possible causes and the proposed fix plan to the user. Proceed with the implementation only after this explanation and the user's confirmation.
- **Branch Management:** Always create a new feature branch from the current branch before starting new work.
